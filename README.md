# Portfolio

A modern, responsive personal portfolio for **Mahima Kukadiya** — AI Engineer & Full-Stack Developer.

Built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion, featuring a dark glassmorphic UI, aurora background, and scroll-reveal animations.

## Live

https://my-portfolio-mahima-kukadiyas-projects.vercel.app

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4 + custom design tokens
- **Animation:** Framer Motion
- **Icons:** lucide-react + inline brand SVGs
- **Deployment:** Vercel

## Sections

Hero · About · Skills · Projects · Experience · Contact

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run build` | Production build         |
| `npm run start` | Run production server    |
| `npm run lint`  | Run ESLint               |
